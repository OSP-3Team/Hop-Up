## 핵심 루프

| 제안 발표 | 현재 |
|---|---|
| 농사 → 발판 구매 → **엘리베이터** → 지고 등반 → 설치·길 연장 | 농사 → 발판 구매 → 등반·설치 → 지대 해금 (→ 300m 엔딩) |

엘리베이터를 빼면서 루프에서 한 단계가 사라졌다. 75·150·225m 지점은 "정거장"이 아니라 **지대 해금 높이**로만 쓰인다.

## 1. 제외

|---|---|---|
| 지대 끝마다 고정 엘리베이터 정거장 3곳 | 없음 | 범위에서 제외 |

## 5. 제안 발표대로 구현된 것

| 항목 | 내용 |
|---|---|
| 높이·지대 | 300m, 4개 지대 (0–75 / 75–150 / 150–225 / 225–300) |
| 발판 | 3종 10 / 25 / 60코인, 지대마다 가격 ×2 (1·2·4·8배) |
| 인벤토리 | 1칸에서 시작, 상점에서 최대 10칸까지 구매 |
| 추락 페널티 | 10m 이상 떨어져 설치한 발판에 착지하면 그 발판 파괴, 계속 낙하 |
| 농사 봇 | 최대 4대, 상태 머신(대기·이동·심기·수확)으로 동작 |
| 지대 보상 | 75m 속성 당근, 150m 황금 당근, 300m 달 도착(엔딩) |
| 황금 당근 | 봇이 키울 수 없음 → 후반에도 직접 하는 농사가 남음 (발표의 설계 리스크 대응) |
| 데이터 | 세이브·밸런스 설정은 JSON (Newtonsoft.Json), 플레이 로그는 CSV |
| 기술 스택 | Unity 6.6, C#, Unity 내장 물리, GitHub |

## 최종 발표 전 확인할 점

- **음식 먹기 UI가 없다.** 요리를 변경 사항으로 소개하지만, 만든 수프를 먹는 기능은 테스트 스크립트에만 있다. 시연하려면 먹기 UI가 필요하다.
- **핵심 루프 그림을 바꿔야 한다.** 발표 자료의 루프에 엘리베이터가 들어 있다.
- **새 게임 시작 아이템은 테스트용 값이다.** 지금은 발판 종류별 10개와 20코인으로 시작한다(`farm_economy.json`의 `newGame`). 이대로면 초반 "농사로 발판을 산다" 단계가 생략된다.
- **장애물을 넣을 때:** 넉백으로 10m 이상 떨어지는 경우도 추락 페널티로 볼지 정해야 한다. 지금 낙하 판정은 낙하 원인을 구분하지 않는다.
